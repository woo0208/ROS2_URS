# ROS 2 기반 초음파 레이더 시스템

## 1. 작품명

**ROS 2 기반 초음파 레이더 시스템 (ROS 2 Ultrasonic Radar System)**

## 2. 작품설명

본 프로젝트는 **초음파 센서와 서보모터를 이용하여 주변 장애물의 방향과 거리를 측정하고, ROS 2를 통해 측정 결과를 실시간으로 시각화하는 시스템**을 개발하는 것을 목표로 한다.

서보모터에 HC-SR04 초음파 센서를 장착하여 좌우로 회전시키고, 각도별로 장애물까지의 거리를 측정한다.

측정한 데이터는 Arduino UNO Q에서 처리한 후 ROS 2 토픽(Topic)을 통해 전달하며, RViz2를 이용하여 장애물의 위치를 시각적으로 확인할 수 있도록 구현한다.

### 주요 기능

1. **초음파 거리 측정**
   - HC-SR04 센서를 이용하여 장애물까지의 거리 측정
   - 센서로부터 수집한 거리 데이터를 처리

2. **서보모터를 이용한 방향 탐색**
   - SG90 서보모터를 이용하여 초음파 센서를 좌우로 회전
   - 각도별 거리 데이터를 수집하여 주변 장애물 탐색

3. **ROS 2 기반 데이터 통신**
   - ROS 2의 Publisher/Subscriber 통신 구조 활용
   - 측정 데이터를 토픽으로 발행하고 다른 노드에서 활용할 수 있도록 구성

4. **장애물 위치 시각화**
   - ROS 2의 RViz2를 활용하여 센서 데이터를 시각화
   - 장애물의 방향과 거리 변화를 실시간으로 확인

## 3. 선정이유

본 프로젝트를 선정한 이유는 **ROS 2의 기본 통신 구조를 학습하면서 실제 하드웨어와 연동되는 시스템을 구현하기 위해서**이다.

ROS 2는 로봇 시스템에서 센서 데이터 처리, 장치 제어, 노드 간 통신 등에 활용되는 소프트웨어 프레임워크이다.

단순히 시뮬레이션 환경에서 ROS 2를 실행하는 것보다 실제 센서와 모터를 연결하여 데이터를 수집하고 처리하는 과정이 ROS 2의 동작 원리를 이해하는 데 도움이 된다고 판단하였다.

또한 초음파 센서와 서보모터는 비교적 간단한 하드웨어 구성을 가지므로 제한된 프로젝트 기간 안에 시스템을 구현하고 검증하기에 적합하다.

이를 통해 다음과 같은 기술을 학습하고자 한다.

- ROS 2의 Node, Topic, Publisher/Subscriber 구조 이해
- 초음파 센서를 이용한 거리 측정 원리 학습
- PWM을 이용한 서보모터 제어
- 실제 하드웨어와 ROS 2 간 데이터 연동
- RViz2를 이용한 센서 데이터 시각화

## 4. 필요기술

### 4.1 하드웨어

| 구성 요소 | 사용 목적 |
|---|---|
| Arduino UNO Q | 센서 및 모터 제어, ROS 2 실행 |
| HC-SR04 초음파 센서 | 장애물까지의 거리 측정 |
| SG90 서보모터 | 초음파 센서 회전 |
| 센서 고정 브래킷 | 초음파 센서와 서보모터 결합 |
| 외부 5V 전원 | 서보모터 전원 공급 |

### 4.2 소프트웨어

| 기술 | 사용 목적 |
|---|---|
| ROS 2 | 노드 간 데이터 통신 및 시스템 구성 |
| Python | ROS 2 노드 구현 |
| Arduino C/C++ | 센서 측정 및 서보모터 제어 |
| RViz2 | 장애물 방향 및 거리 시각화 |
| Linux | ROS 2 실행 환경 |

### 4.3 핵심 구현 기술

**① 초음파 거리 측정**

HC-SR04 센서의 Trigger와 Echo 신호를 이용하여 초음파의 왕복 시간을 측정하고, 이를 거리 데이터로 변환한다.

**② PWM 기반 서보모터 제어**

서보모터를 일정 각도 간격으로 회전시켜 여러 방향의 거리 데이터를 수집한다.

**③ ROS 2 Topic 통신**

Arduino UNO Q에서 수집한 데이터를 ROS 2 노드로 전달하고, `sensor_msgs/msg/LaserScan` 메시지 형식으로 `/scan` 토픽을 발행한다.

**④ RViz2 시각화**

ROS 2 토픽으로 전달된 데이터를 RViz2에서 표시하여 장애물의 방향과 거리를 확인한다.
